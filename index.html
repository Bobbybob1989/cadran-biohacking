Réglages — clé API personnelle

Nécessaire pour Monica en dehors de Claude.ai

Pour utiliser Monica sur cet appareil (téléphone, hébergement autonome), fournis ta propre clé API. Elle est stockée uniquement dans la mémoire de ce navigateur (localStorage) — jamais envoyée ailleurs qu'au fournisseur choisi ci-dessous.

Anthropic : clé créée sur console.anthropic.com (compte API séparé de ton abonnement Claude.ai, facturé à l'usage).
OpenRouter : un seul compte donne accès à plusieurs modèles, dont Claude.
OpenAI : clé créée sur platform.openai.com.
